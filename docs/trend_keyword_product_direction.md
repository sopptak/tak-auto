# TAK AUTO: 트렌드 키워드 중심 개발 방향

## 제품 목표
TAK AUTO의 최우선 기능은 특정 업종(예: 법원경매) 콘텐츠 제작이 아니라, 여러 공개 채널에서 변화하는 트렌드 키워드를 발견하고 콘텐츠 기회를 평가하는 것이다.

## 현재 구현 범위
- 공개 RSS에서 제목·짧은 요약·URL·발행일 수집
- 중복 후보 제거 및 기존 SCOUT SCORE로 소재 우선순위 계산
- 전체 수집 후보를 대상으로 반복 키워드 추출
- 서로 다른 수집 출처에서 반복된 정도를 별도로 표시

## 측정의 한계
현재 반복 키워드는 등록된 RSS 안에서의 관측값이다. 네이버 데이터랩 검색량, Google Trends, YouTube 인기 검색어, Threads 반응, 전체 인터넷의 관심도를 측정한 값이 아니다. 제품 화면과 보고서에서 이를 '실시간 검색량' 또는 '대중 인기 순위'로 표현하지 않는다.

## 개발 우선순위
1. **데이터 소스 확대**: 한국어·국내 이슈 중심의 공식 공개 RSS 및 합법적인 트렌드 API를 추가한다.
2. **키워드 정규화**: 조사/어미, 동의어, 고유명사, 복합명사 처리를 개선하고 원문 후보로 역추적할 수 있게 한다.
3. **상승세 측정**: 일별 스냅샷을 축적해 최근 빈도와 기준 기간 빈도를 비교한다. 데이터가 쌓이기 전에는 상승세를 단정하지 않는다.
4. **콘텐츠 기회 점수**: 관심 신호, 상승세, 경쟁도, 채널 적합성, 제작 난이도를 분리해 점수화하고 각 점수의 근거를 공개한다.
5. **콘텐츠 변환**: 선정 키워드별 블로그·Threads·쇼츠 초안을 만들되 근거 링크와 사실/해석을 분리한다.
6. **성과 환류**: 실제 조회·클릭·저장·댓글 데이터를 연결해 키워드 점수와 제작 전략을 개선한다.

## 운영 원칙
- 특정 분야는 선택 가능한 카테고리로 두고 전체 제품의 기본 방향으로 고정하지 않는다.
- 근거가 없는 검색량·인기·상승세 수치를 만들지 않는다.
- 콘텐츠 생성과 게시를 분리한다. 자동 생성 결과는 검토 대기 상태로 두며 사람 승인 없이 게시하지 않는다.
- 외부 플랫폼의 이용약관과 공식 API 제한을 준수한다.
