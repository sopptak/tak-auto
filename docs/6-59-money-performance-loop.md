| 값 | 정의 |

## 4. 실제 시급 · 예상 대비 실제 — `calibration()`

예상값을 알던 완료 기록만 쓴다(빠른 수익 기록·작업 없는 정산은 제외). 시간 가중 평균:

- 평균 예상 시급 = Σ(예상 보상×환산)×60 ÷ Σ예상 분
- 평균 실제 시급 = **같은 기록들**의 Σ실제 원×60 ÷ Σ실제 분
- 예상 대비 = (실제 − 예상) ÷ 예상, 보정 비율 = 실제 ÷ 예상

표본이 `min_samples_for_hourly`(3)건 미만이면 숫자 옆에 **"(n/3건 · 데이터 부족)"**을 붙이고 보정에는 쓰지 않는다.
**검증 중 발견·수정**: 6-57의 `platform_stats`는 "예상 대비"를 계산할 때 실제 쪽에 예상값 없는 기록까지 넣어, 같은 플랫폼 카드에 "예상 대비 −21.9%"와 "4,800 → 3,789원(−21.1%)"이 함께 떴다(빠른 수익 기록이 섞인 경우). 이제 두 곳 모두 같은 기록끼리 비교한다(회귀 테스트 추가).

## 5. 예상 시급 보정

새 기회/작업 카드: `예상 시급 4,800원` 아래에

## 6. 개인화 우선순위 — `learned_priority()`

- **루틴 플랫폼 모두**가 확인 `min_checks_for_priority`(=5, `MIN_CHECKS_FOR_LEARNED_PRIORITY`)회 이상일 때만 계산. 하나라도 모자라면 설정(기존) 순서를 그대로 쓰고 `추천 확인 순서: 데이터 수집 중 — 패널나우 3/5 · 오베이 0/5 …`를 보여준다(일부만 데이터 있을 때 섞어서 추천하지 않음).
- 점수 = **확인 1회당 작업 수익**(발견률·완료율·보상 크기가 한 숫자에 반영됨). 같으면 실제 시급, 그다음 기존 순서.
- 화면: `오늘 추천 확인 순서 ① 오베이 ② 패널나우 ③ 헤이폴 ④ 네이버 애드포스트` + "내 기록 기준 — 플랫폼 평가가 아니라 지금까지 내 기록" + 플랫폼별 확인 1회당 수익, 루틴 카드도 그 순서로 번호가 붙는다.
