# 6-66 CHOICE100 BOARD GAME CORE — QUIZ → REWARD → DICE → BOARD

> 선택100의 두 번째 축인 **보드게임 코어**의 작동하는 G0/G1 프로토타입이다. 세계사 테마 미니 게임 **선택100 WORLD — 세계의 길(가제)**이 실제 브라우저에서 12턴 플레이된다.
> 금융 선택100(`game_lab/choice100/`, 6-64·6-65)은 그대로 두었다. 배포·광고·결제·로그인·서버·외부 API는 없다.

## 1. Executive Summary

- 루프: **세계사 퀴즈 → 정답이면 🎲 주사위 특권(홀/짝 선언) → 실제 무작위 주사위 → 적중이면 🧭 항로 조정권(도착 칸 −1/0/+1 선택) → 보드 이동 → 칸 효과·선택(도시·교역·탐험·사건·보너스·퀴즈·휴식) → 교훈 → 다음 퀴즈**.
- "지식 → 게임 실력" 연결이 숫자로 확인됐다. 시뮬레이션에서 정답률 30% → 90%로 평균 점수가 모든 전략에서 오른다(무작위 전략 249 → 383, 탐험 288 → 489).
  원인은 세 가지다. 선언권으로 도착 칸을 고른다. 지식이 높으면 탐험에서 발견이 두 배다. 지식 자체도 점수가 된다.
- 주사위는 투명하다:
  - 1,200판 14,400굴림에서 면별 2,341~2,438(기대 2,400)
  - 홀짝 선언 적중률 0.507(기대 0.5)
  - 기본 rng 6만 굴림 카이제곱 검정 통과
  - 조작 코드 없음(테스트)
- 데이터: 세계사 퀴즈 15개(모두 위키백과 영문 문서로 확인, URL·확인일 기록), 보드 24칸(CITY 5 · TRADE 5 · EXPLORE 4 · EVENT 3 · QUIZ 3 · BONUS 2 · REST 1 · START 1).
- 테스트: node 보드 14개 + Python 11개(신규 `tests/test_6_66_board.py`).
  실제 Chrome에서 정답 루트 3판 + 오답 루트 3판 + 혼합 2판 완주, 390px 14개 화면 상태 가로 넘침 0, 새 빌드 콘솔 오류 0.

## 3. Quiz DNA

퀴즈 게임의 구조(빠른 문제·즉시 정답 확인·짧은 행동·지식이 진행에 직결)만 가져왔다.
- 한 턴 첫 행동이 퀴즈 한 문제(탭 한 번 / 키 1~4)다.
- 정답·오답과 한 줄 해설이 즉시 같은 화면에 뜬다. 출처도 같이 보인다.
- 정답이 **점수가 아니라 게임 자원(주사위 특권)**으로 바뀐다. 이번 작업의 핵심이다.

## 4. Board Game DNA

주사위 보드 계열(칸·이동·자산·사건·누적)과 대항해 계열(세계를 돌아다니는 느낌·교역·탐험·지역)의 **구조만** 참고했다.
특정 게임의 코드·이미지·맵·캐릭터·UI·문구·음악·데이터는 쓰지 않았다. 지도는 24칸 격자이고, 아이콘은 유니코드 이모지다.

## 5. Quiz → Reward → Dice → Board

```
[🌍 퀴즈] ─정답→ [⭕ + 📚지식+1 + 해설·출처] → [🎲 특권: 홀수 1·3·5 / 짝수 2·4·6] → [주사위] ─적중→ [🧭 도착 칸 −1/0/+1 선택] ┐
    │                                                                              └─빗나감→ 나온 만큼 이동 ─────────────┤
    └─오답→ [❌ 정답·해설·출처] → [🎲 주사위 굴리기] → 나온 만큼 이동 ─────────────────────────────────────────────────┤
                                                                                                                ▼
                  [칸: CITY(교역/도서관/출항) · TRADE(사기/팔기/지나가기) · EXPLORE(탐험/지나가기) · QUIZ(보너스 퀴즈) · EVENT·BONUS·REST(자동)]
                                                                                                                ▼
                                                            [결과 칩 + 📜 교훈(출처)] → [다음 퀴즈 ▶] … 12턴 → [여행 결과]
```

- 한 턴은 한 화면에서 아래로 쌓인다. 지난 단계는 흐리게 남아 맥락이 끊기지 않는다.
- 클릭 수(Chrome 실측): 12턴에 44~54번(턴당 약 4번: 답·선언/굴리기·(조정)·칸 선택·다음).
- 정답/오답 루트 모두 끝까지 진행된다. 오답도 게임이 계속되고 가혹하지 않다(특권만 없다).

## 6. Dice parity privilege

- 정답 보상 `DICE_PARITY` = **굴리기 전에 홀/짝을 선언하는 권리**다. 주사위 확률은 바꾸지 않는다.
  - 홀수 = {1,3,5}, 짝수 = {2,4,6} → 선언한 쪽이 나올 확률 **정확히 3/6**.
  - 적중 보상(G1): **항로 조정권** — 도착 칸을 한 칸 앞·그대로·한 칸 뒤 중에서 고른다. 0칸 이동은 뺀다(1이 나오면 1·2 중에서).
  - 빗나가면 나온 눈만큼 이동한다(벌칙 없음).
- 오답: 선언권이 없다 → 그냥 굴린다(`declare()`는 오류, `roll()`만 가능 — 테스트).
- 화면은 "🎲 주사위 특권 획득! 어느 쪽을 선언할까요? (확률 3/6)" → "⚃ 4 · 홀수를 선언했습니다 → 빗나감"처럼 결과를 그대로 보여 준다.
  굴리는 연출(0.4초)은 결과가 정해진 뒤 화면만 도는 것이다. 연출 중 화면을 떠나면 옛 연출은 버리고 저장된 결과로 이어진다.

## 7. Board architecture

- `game_lab/board/engine.js`: DOM이 없고 도메인을 모른다. phase 기계다: `quiz → parity | roll → steer → cell → turn_end → quiz … → end`.
  - 단계가 맞지 않는 호출은 오류다(테스트).
- 칸 효과는 데이터로 정한다:
  - `effect`(자동)
  - `choices[]` — `effects` / `cost` / `buy{good,qty,price}` / `sell{good,price}` / `bonus_if{stat,gte,effects,text}` / `lesson`
  - QUIZ 칸의 `quiz` 보상
- 이동: 보드를 돈다(24칸). START를 지나면 `lap_bonus`(코인 +20)를 받는다. 위치는 항상 0~23이다(시뮬레이션 1,200판에서 매 단계 검사).
- 불가능 상태를 막는다:
  - 코인·짐칸이 모자라면 선택지 비활성 + 이유 표시
  - 팔 물건이 없으면 팔기 비활성
  - 모든 칸에 늘 고를 수 있는 선택지 1개(검증)
  - 음수·NaN 없음(클램프 + 시뮬레이션 검사)

## 8. World History prototype — 선택100 WORLD (가제 "세계의 길")

- 플레이어는 가상의 탐험가·상인이다. 12번 항해로 코인·지식·탐험을 모은다.
- 24칸 항로: 출발 항구 → 리스본 → 지중해 시장 → 대서양 연안 → 학자의 배 → 알렉산드리아 → 흑사병의 기억 → 홍해 교역소 → 순풍 → 아프리카 남단 → 코지코드 → 인도양 향신료 시장 → 항구 휴식 → 믈라카 해협 → 인쇄술의 확산 → 광저우 → 비단 시장 → 학자의 배 → 먼 바다 → 좋은 거래처 → 나가사키 → 산업혁명의 소식 → 신대륙 교역소 → 학자의 배 → (출발 항구).
- 화면에 표시하는 문구: **"보드 경로는 게임용 가상 항로입니다. 실제 역사적 항로·시대 순서와 다릅니다."**
- 퀴즈와 교훈은 출처를 남긴 역사 사실이다. 보드의 항로·순서·가격·사건 효과는 게임 설정이다(면책 문구).

## 9. Exploration

- EXPLORE 칸: [탐험한다 (10코인)] → 탐험 +1 / [지나간다].
- **지식 관문**: 칸마다 필요 지식(2·3·4·5)이 있다. 지식이 그 이상이면 "지식 덕에 해류를 읽어 먼 연안까지 갔다!" → 탐험 +2, 코인 +20. 퀴즈를 많이 맞힐수록 탐험이 두 배가 된다.
- 교훈 예: "바스쿠 다 가마는 아프리카 남단을 돌아 1498년 인도 코지코드에 도착했다." (출처 표시)
- 다음 지역 잠금 해제·탐험 토큰(EXPLORE_TOKEN)은 설계만 했다(21장).

## 10. Trade

- 상품 2개: 🌶️ 향신료, 🧵 비단. 짐칸 6, 한 번에 3개씩 산다.

| 상품 | 싸게 사는 곳 | 비싸게 파는 곳 |
|---|---|---|
| 향신료 | 인도양 시장 8, 코지코드 10, 홍해 14 | 리스본 30, 신대륙 28, 지중해 26 |
| 비단 | 비단 시장 10, 광저우 12 | 신대륙 30, 리스본 26 |

- 싸게 사서 먼 곳에서 판다. 한 번 왕복에 +40~60이다.
- 도시에서도 교역을 할 수 있다: [교역] · [도서관(지식 +1, 10코인)] · [바로 출항].
- 전략: 주사위는 이동만 정한다. 어디서 사고팔지, 탐험·공부에 코인을 쓸지는 플레이어 선택이다. 퀴즈 보상은 도착 칸을 고르는 힘이다.

## 11. Lesson

- EVENT·EXPLORE·일부 TRADE 칸과 모든 퀴즈 해설에 한두 문장 교훈과 **출처(위키백과 영문 URL, 2026-09-27 확인)**를 붙였다.
- 흐름을 막지 않도록 결과 카드 안 한 블록으로 둔다. 한 판에 교훈 16~22개가 노출됐다(Chrome 6판 실측).
- 사건 예:
  - 흑사병의 기억(코인 −15): "흑사병은 1346~1353년 유럽을 휩쓸어 인구의 30~60%가 숨진 것으로 추정된다."
  - 인쇄술의 확산: 지식 +1
  - 산업혁명의 소식: 코인 +20

## 12. Player state

`vars{coin, knowledge, exploration}`, `cargo{spice, silk}`, `pos`, `turn`, `laps`, `phase`, 퀴즈 순서(판마다 섞음, 한 판에 같은 문제 반복 없음), 맞힌 수·선언 수·적중 수.
종합 점수 = 코인×1 + 지식×15 + 탐험×20(`score_weights`).

| 엔딩 | 조건 |
|---|---|
| 🏆 세계사 탐험가 | 점수 ≥ 520 |
| 💰 대상인 | 코인 ≥ 250 |
| 📚 항해하는 학자 | 지식 ≥ 12 |
| 🧭 개척자 | 탐험 ≥ 5 |
| ⛵ 떠돌이 여행자 | 기본 |

모든 엔딩은 "게임 결과이며 실제 역사 지식 평가가 아닙니다"라고 표시한다. 두 번째 판부터 지난 항해와 비교한다(점수·코인·지식·탐험).

## 13. Reward architecture

`REWARD_TYPES = DICE_PARITY, MOVE_BONUS, TRADE_BONUS, EXPLORE_TOKEN, PROTECTION, COIN`.

| 보상 | G1 | 설계(다음) |
|---|---|---|
| DICE_PARITY | ✅ 홀짝 선언 → 적중 시 항로 조정(±1) | 연속 정답 시 ±2 |
| MOVE_BONUS | 스키마만 | 정답 연속 3회 → 이동 +1~+2 선택 |
| TRADE_BONUS | 스키마만 | 교역 칸에서 가격 10% 유리 |
| EXPLORE_TOKEN | 스키마만 | 지식 관문 없이 탐험 보너스 1회 |
| PROTECTION | 스키마만 | 손해 사건 1회 막기 |
| COIN | 스키마만 | 정답 즉시 코인 |

데이터는 `rewards.<TYPE> = {status:"planned"}`로 자리를 잡아 두었다. 모르는 보상 타입은 검증 오류다.

## 18. Probability verification

| 검증 | 결과 |
|---|---|
| 코드 | `1 + Math.floor(this.rng() * 6)` 한 곳. rng 호출은 주사위와 퀴즈 섞기 2곳뿐(테스트가 개수 고정). 기본 rng = `crypto.getRandomValues` |
| 균등성(기본 rng, 6만 굴림) | 카이제곱 < 20.52(df 5, p = 0.001), 홀수 비율 0.5 ± 0.01 — 테스트 |
| 적중 규칙 | 1~6 × 홀/짝 12가지 모두 "적중 ⟺ 선언 = 눈의 홀짝" — 테스트 |
| 시뮬레이션 1,200판 | 굴림 14,400, 면별 2,438 · 2,406 · 2,341 · 2,427 · 2,397 · 2,391. 선언 8,607회, 적중 4,366회 = **0.507** |
| 오답일 때 | 선언 불가(`declare` 오류), `parity=null`, `hit=null` |

코드·문서·화면 모두 "선언한 쪽이 나올 확률 3/6"으로 같다.
