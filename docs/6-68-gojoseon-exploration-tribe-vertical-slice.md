# 6-68 선택100: 대한민국 — 고조선 「첫 번째 땅」 Vertical Slice (탐험 + 부족 통합)

> 게임 전체의 시작점을 만들었다: **탐험 → 발견 → 부족과의 만남 → 선택 → 통합 → 새 지역 → 성장 → 고조선 건국**.
> 실행: `py -m http.server 8790 --bind 127.0.0.1 -d game_lab` → http://127.0.0.1:8790/rpg/gojoseon/
> 주몽(6-67)은 영웅별 미니게임 프로토타입으로 그대로 두었다. 성장·보드·기록 엔진은 새로 만들지 않고 재사용했다.
> **재미 판정은 게임 디렉터 몫이다(15장 FUN_VALIDATION_REQUIRED).**

## 1. 목표

- "옛날 게임의 재미로 역사를 플레이한다." 학습게임이 아니라 성장 RPG다. 역사는 발견·선택·보상 안에 녹인다.
- 첫 1시간의 감정 흐름:

  | 감정 | 게임 장치 |
  |---|---|
  | 어디로 가 볼까? | 안개 지도 + 방향과 소리 힌트: "⬅ 서쪽 · ❓ 물소리가 들린다" |
  | 새로운 장소를 발견했다 | "✨ 새 장소 발견!" + EXP |
  | 새로운 부족을 만났다 | 만남 사건 |
  | 어떻게 대응할까? | 선택 4가지: 관찰 / 선물·교역 / 도움 / 위협 |
  | 이 부족이 우리와 함께하게 됐다 | 🤝 연합 + 어빌리티·동료·인구 |
  | 새 지역이 열렸다 | 🛤️ 새 길 |
  | 저 지역도 가 보고 싶다 | 🔒 이유 표시("어빌리티 ‘추적’ 필요") |
  | 고조선 건국에 도달했다 | 아사달 모임: 이름·법·이념을 정한다 |

## 2. 게임 루프

```
[지도(안개)] → 이동(식량) → 첫 방문: 발견 EXP / 부족이면 만남 사건
   ↓
[장소] 🔍 둘러보기(순서 있는 발견 2~3개: 새 길·아이템·지식·자원·단서) · 🧺 채집 · 🎮 미니게임
   ↓
[부족] 만남 선택 → 신뢰 · 후속 사건 → 요청(자원·장소·지식·미니게임) → 🤝 연합 또는 ⚔️ 복속
   ↓
통합 보상: 어빌리티(새 플레이 방법) · 아이템 · 동료 · 인구·명성 · 새 길
   ↓
부족 3곳 이상 → 아사달 벌판 → "지금 회의를 열까, 남은 부족도 데려올까?"
   → 회의: 나라 이름 → 법 세 가지 → 이념 → 엔딩 "내가 만든 나라"
```

- **선택 → 결과 → 다음 선택**: 만남의 "도움"은 후속 사건(늑대 떼·사흘째 비)으로 이어진다. 거기서 한 선택이 요청 해결과 신뢰로 이어진다.
  못 해낸 요청은 "다시 돕기"로 사건을 다시 부른다.
- **지식·어빌리티가 새 플레이를 연다**:

  | 얻은 것 | 열리는 플레이 |
  |---|---|
  | 추적 | 숲의 숨은 굴(식량 +8), 산마루 → 구리 골짜기 길 |
  | 농사 | 채집 보너스 |
  | 청동 도구 | 안개 고개 통과, 구리 채집 보너스 |
  | 교역로 | 강어귀에서 소금 교역 채집, 아사달 물길 |
  | 뗏목 | 강어귀 뱃길 |
  | 지식 `k_river` | 물길 찾기 힌트 |
  | 지식 `k_bronze_mix` · `k_bipa` | 청동 녹이기 힌트 |
  | 고인돌 언덕 발견 | 홍수 때 "높은 땅" 선택지 |

- **무작위는 사냥 보드의 주사위뿐**이다. 무엇을 발견하는지는 이동·선택·지식·어빌리티가 정한다.

## 4. historical_fact / historical_record / mythology / legend / game_setting

RPG 엔진의 역사 상태에 **`mythology`를 추가**했다(6-67의 4값 + 신화, 추가만 함). 모든 장소·발견·사건·선택지·부족·지식·아이템·어빌리티가 태그를 가진다(Python 테스트).

| 태그 | 이 슬라이스의 예 |
|---|---|
| historical_fact | 고인돌(청동기 무덤), 비파형 동검(청동기 유물·조립식) |
| historical_record | 8조법 3조목(『한서』 지리지), 단군왕검 해석(제정일치), 나라 이름 ‘조선’ |
| mythology | 곰·호랑이·웅녀 이야기, 단군왕검의 아사달 도읍, 홍익인간 |
| legend | (이번 슬라이스에는 쓰지 않음 — 태그는 준비) |
| game_setting | 부족 4곳과 그 이름·성격, 지명 배치, 모든 대화·사건, 아이템, 어빌리티, 부족 통합과 회의로 세우는 건국 과정, "아사달 벌판"이라는 게임 무대 |

- 신화는 "『삼국유사』가 전하는 신화"로 말한다. 사실 배지를 달지 않는다(테스트).
- 법 세우기의 선택지 중 기록된 조항에는 역사 기록 배지와 교훈(출처)을 붙인다. 다른 선택지는 "(게임 설정)"으로 둔다.

## 6. 채택/비채택 이유

**이번에는 아무것도 채택하지 않았다. 기존 엔진을 재사용했다.** 판단 기준은 "직접 구현보다 재사용이 명백히 빠르고 안정적인가?"였다.

- 기존 3개 엔진(선택100·보드·RPG)은 합쳐 53KB이고, 의존성 0, 빌드 단계 없음, 테스트 수백 개로 보호된다.
- 이번에 필요한 것은 노드 지도(12곳)·조건 길·선택 사건·부족 상태·작은 미니게임이다. 모두 데이터 구동 로직이고, 렌더링이 어렵지 않다.
- Phaser 한 파일(1.3MB)이 우리 게임 전체보다 25배 크다. 그래픽을 우선하지 않는다는 원칙에도 어긋난다.
- ink는 좋은 도구지만 대화를 `.ink` 파일로 옮기면 역사 태그·출처(`historical_status`, `source`)가 구조화 데이터에서 빠진다. 컴파일 단계도 생긴다.
- **재사용한 내부 자산**:
  - 6-67 RPG 엔진: EXP·레벨·지식 → 정책·아이템·스킬(= 어빌리티)·동료·관계·저장
  - 6-66 보드 엔진: 숲 사냥 미니게임
  - 6-65 analytics.js: 로컬 기록
  - 모바일 CSS
- **도입 트리거(기록)**:
  - 실시간 액션 미니게임(광개토대왕 XT 액션, 이순신 해전)이 생기면 → KAPLAY(가벼움) 또는 Phaser
  - 대화량이 장당 수십 개를 넘으면 → inkjs(태그는 ink 태그 문법으로 옮기는 방안 검토)
  - 타일 지도가 필요하면 → Tiled로 만들고 Phaser/KAPLAY로 읽기
- 엔진 변경은 두 가지, 모두 추가형이다:
  1. `HISTORICAL`에 `mythology` 추가(6-67 테스트 기대값 갱신)
  2. 능력치별 최솟값 `stat_min`(기본 0 — 명성이 음수로 내려가 복속의 대가가 보이게)

  주몽 데이터·테스트는 그대로 통과한다.

## 7. 맵 구조 (5×4 격자, 12곳, 길 15개)

```
         x0            x1            x2            x3            x4
 y0                 🏛️아사달      
 y1   🌲큰 나무     (안개 사이)    🌫️안개 고개                  🟥붉은 바위
 y2   🪨고인돌      🌾너른 들                    ⛰️매봉 산마루    🔥장인 마을
 y3   ⛵강어귀      🌊큰 강 나루   ⛺야영지(시작)  🌳참나무 숲
```

- 시작 때 보이는 곳은 야영지와 이웃 두 곳(❓ + 방향 + 소리 힌트)뿐이다. 나머지 길은 **숨어 있다가 발견으로 드러난다**.
  - 강의 발자국 → 들
  - 매 깃털 → 산마루
  - 들 끝 언덕 → 고인돌 → 큰 나무
  - 망치 소리 → 장인 마을
  - 짠 바람 → 강어귀
- 조건 길:

  | 길 | 조건 |
  |---|---|
  | 구리 골짜기(산마루 쪽) | 추적 |
  | 강어귀 | 뗏목, 또는 물길 찾기 성공(먼 길) |
  | 안개 고개 | 청동 도구 |
  | 아사달 | 부족 3곳 |

- 이동에는 식량이 든다. **식량이 없어도 갈 수는 있다**(굶주린 행군: 인구 −3). 식량 때문에 갇히지 않게 했다 — 실제 막힘을 시뮬레이션으로 찾아 고쳤다.

## 8. 부족 구조 (4곳, 모두 game_setting)

| 부족 | 성격 | 요청(통합 조건) | 연합 보상 | 복속 조건·대가 |
|---|---|---|---|---|
| 🏹 매깃 사냥 부족(산마루) | 사냥·활·신호 | 실력 증명(숲 사냥 성공 또는 늑대 막기) + 겨울 식량 8 | 어빌리티 추적, 동료 매깃, 인구 +20, 명성 +5, 구리 골짜기 길 | 위협 + 인구 30 / 명성 −8, 동료 없음 |
| 🌾 들녘 농경 부족(너른 들) | 농사·정착 | 홍수 넘기기(둑: 인구 25, 또는 고인돌 언덕을 알면 높은 땅) + 잔치 식량 6 | 농사, 뗏목, 동료 들녘 어른, 지식 ‘강은 바다로’, 인구 +30 | 위협 + 인구 30 |
| 🔥 불꽃 골 장인 부족 | 청동·도구 | 구리 3 + 청동 녹이기 시험(미니게임) | 청동 도구, 비파 모양 청동검(상징), 지식 비파형 동검, 동료, 안개 고개 길 | 위협 + 인구 40 |
| ⛵ 물길 상인(강어귀) | 교역·소식 | 소금 교역(식량 8) | 교역로, 동료 물길 상인, 명성 +10, 아사달 물길 | 위협 + 인구 40 |

- 신뢰 게이지(연합에 4 필요) + 요청 체크리스트를 보여 준다. 못 채운 이유와 방법은 "how" 문구로 보여 준다
  (예: "참나무 숲 ‘숲 사냥’에서 짐승을 잡거나, ‘다시 돕기’로 늑대 문제를 해결하자.").
- 🎁 **선물**(식량 4 → 신뢰 +1)은 되풀이할 수 있다. 첫 만남에서 무엇을 골랐든 신뢰에 닿을 길이 남는다 — 실제 막힘을 찾아 넣었다.

## 9. 선택 구조

- 만남 선택 4종:

  | 선택 | 효과 |
  |---|---|
  | 👀 관찰 | 신뢰 +1, 정보·지식 |
  | 🐟/🟥 선물·교역 | 자원 소모, 신뢰 +2 |
  | 🤝 도움 | 신뢰 +1, 후속 사건 |
  | 💢 위협 | 신뢰 −2, 명성 −3, 복속 가능 |

  조건이 안 맞는 선택지는 비활성으로 두고 이유를 보여 준다(예: "인구 25 필요").
- 후속 사건 예:
  - 늑대 떼: 울타리(인구 10) / 밤새 불 지키기(식량 3) / 나중에
  - 사흘째 비: 둑(인구 25) / 높은 땅(고인돌 언덕을 발견했으면) / 기다리기
- 건국 회의 선택:
  - 나라 이름: ‘조선’(역사 기록) 또는 새 이름
  - 법 3개: 기록된 조항 또는 다른 법
  - 이념: 홍익인간(신화) / 강한 나라 / 배부른 나라
- 엔딩은 연합·복속 수, 발견한 땅, 지식을 반영한다:

  | 엔딩 | 조건 |
  |---|---|
  | 🤝 모두가 함께 세운 나라 | 4곳 연합, 복속 0 |
  | ⚔️ 힘으로 묶은 나라 | 복속 2 이상 |
  | 📚 지혜로 세운 나라 | 지식 8 이상 |
  | 🗺️ 땅을 아는 나라 | 11곳 이상 발견 |
  | 🏕️ 작지만 단단한 나라 | 기본 |

  "내가 만든 나라" 화면에 이름·이념·함께한 부족(🤝/⚔️)·정한 법·발견한 땅·지식·인구·명성·동료를 보여 준다.

## 13. 발견된 문제 (찾아서 고친 것)

| 문제 | 원인 | 고침 |
|---|---|---|

## 15. FUN_VALIDATION_REQUIRED

AI는 재미를 판정하지 않았다. 아래는 관찰 근거이고, **판정은 게임 디렉터가 한다.**

| 항목 | 관찰 근거 | 판정 |
|---|---|---|
| 첫 탐험 욕구 | 시작 화면에 ❓ 두 곳 + "⬅ 서쪽 · 물소리가 들린다 / ➡ 동쪽 · 짐승 울음" | FUN_VALIDATION_REQUIRED |
| 다음 지역을 가고 싶은가 | 발견마다 🛤️ 새 길 알림, 🔒 이유(추적·청동 도구·부족 3곳) | FUN_VALIDATION_REQUIRED |
| 부족을 통합하고 싶은가 | 연합 보상이 새 플레이(어빌리티·길·동료)로 바로 보임 | FUN_VALIDATION_REQUIRED |
| 선택의 의미가 느껴지는가 | 위협 → 복속 가능·명성 하락·동료 없음, 엔딩이 달라짐(위협 중심 57/60이 ‘힘으로 묶은 나라’) | FUN_VALIDATION_REQUIRED |

| 반복 플레이 욕구 | 엔딩 5종, 이름·법·이념 선택, 연합/복속 경로 | FUN_VALIDATION_REQUIRED |
