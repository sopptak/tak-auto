회원 화면 카드 구조(실제): `[종류: 제휴 조사] [제목] No. 응답시간 적립일정 포인트 [번호] [N분] [실시간 적립] [NP] 설문 참여하기`.
로그아웃 예시 화면과 순서는 같았지만 트리에서는 칸이 빠지므로 어댑터를 바꿨다:

- **자리 대신 모양으로 읽기**: 번호 `[a-z]\d{2,}`, 시간 `N분`, 포인트 `NP`, 적립일정 `…적립`. 빠진 칸은 비워 둔다(추측 안 함).
- **트리 입력 지원**: `generic "c001" [ref_102]` 줄에서 이름만 뽑는다. 트리에 "로그아웃"이 없으면 로그인 안 된 것으로 본다(안전 쪽).
- 에이전트 허용 도구에 `read_page`(읽기 전용) 추가. 지시문: get_page_text가 비면 read_page를 한 번 부르고 결과를 그대로 넘길 것, 팝업은 누르지 말 것.
  클릭·입력·JS 도구는 여전히 없다.
- 병합 보강: 트리 읽기에 빠진 값(시간 등)이 전에 읽은 값을 **지우지 않음**. 보상이 안 읽혀 검토로 간 기회도 "보였음"으로 처리
  (실제 버튼 실행에서 c001이 `disappeared`로 잘못 표시되는 버그를 발견해 고쳤고, 다음 실제 실행에서 `active`로 돌아온 것을 확인).
